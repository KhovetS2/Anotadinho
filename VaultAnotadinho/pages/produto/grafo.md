Grafo visual das conexões entre páginas via `[[wikilinks]]` — todas as
páginas do vault viram nós, cada wikilink resolvido vira uma aresta.
Útil pra navegar visualmente as conexões entre [[Missão]], [[Roadmap]]
e as specs/decisões conforme o vault cresce.

Este texto nunca aparece renderizado (páginas `type: graph` mostram só
o grafo) — fica aqui só de referência caso o tipo seja trocado de
volta pra "Página normal".
