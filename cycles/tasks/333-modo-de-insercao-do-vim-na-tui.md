# 333 — Modo de inserção do vim

A pergunta do rodapé virou o modo de inserção: cursor de texto (a célula
em vídeo inverso), `←`/`→`, `Home`/`End`, `Backspace`/`Delete`, `Ctrl+W`
(palavra) e `Ctrl+U` (até o começo). `Esc` CONFIRMA, como no vim —
desistir é `u` depois. `i`/`I` começam com o cursor no começo, `a`/`A`
no fim, `cc` vazio.
