# Calendar View

## Objetivo
View de calendário mensal mostrando páginas com property `date:: YYYY-MM-DD`.
Click na data mostra/abre a página. Navegação entre meses.

## Critérios
- [ ] Calendário mensal renderizado
- [ ] Páginas com `date::` aparecem nos dias
- [ ] Click no dia abre a página
- [ ] Navegação mês anterior/seguinte
- [ ] Integração com kanban: tasks com ambas properties aparecem nos 2
