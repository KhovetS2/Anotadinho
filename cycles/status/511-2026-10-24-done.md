# 511 — TUI: colar do terminal — done

## O que foi feito

- **`crates/tui/src/main.rs`:** liga e desliga a colagem em bloco, e
  `Event::Paste(texto)` vai pra `app::colar`.
- **`crates/tui/src/app.rs`, `colar`:** manda o texto pra onde se está
  digitando:
  - o editor de código;
  - a aba Código do construtor;
  - a inserção de bloco, numa linha só;
  - o rascunho da conversa;
  - os outros campos, por tecla e sem o Enter.

  Fora de um campo, só avisa.
- **`editor_codigo.rs`:** `colar` insere o texto como veio, num passo do
  desfazer.
- **`componentes.rs`:** `Campo::inserir`.
- **`construtor.rs`:** `colar` na aba Código.

## Como foi verificado

- `cargo test -p anotadinho-tui`: 408 testes. Os três novos cobrem:
  - no editor, colar `if x {\n    y();\n}` dentro de uma função não soma
    recuo, e Ctrl+Z desfaz tudo de uma vez;
  - na inserção, a quebra vira espaço;
  - fora de um campo, `dd\nG` não move o cursor e aparece o aviso.
- **Na fronteira (tmux, a TUI de verdade, o mesmo texto colado no editor
  aberto dentro de `fn a() {`):**
  - com `paste-buffer -p` (colagem em bloco), o arquivo ficou
    `    if x {` / `    y();` / `}`, como veio;
  - sem `-p` (uma tecla por caractere, o caminho antigo), ficou
    `    if x {` / `            y();` / `        }`, com o recuo somado.
- `cargo check` no alvo do Windows passa.
