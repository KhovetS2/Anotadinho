# Ciclo 135 - done

## Resumo

Embeds inline (kanban/calendário/tabela dentro do corpo de uma
página) nunca tiveram suporte de teclado — só mouse. Retrofit de
`tabindex` + Enter/Espaço reaproveitando `keyboard_activate.rs`, na
mesma ação que o clique já dispara. Escopo ajustado conscientemente
durante a implementação (ver Notas do arquivo de task): sem atributos
`data-nav-*` do nav-mode (não teriam efeito, Tab nativo já resolve),
calendário só na visão Mês (Semana/Dia ficam pra outro ciclo se
virar necessário).

## Arquivos criados/modificados

- `ui/src/components/embeds/inline_kanban.rs` — card
- `ui/src/components/embeds/inline_calendar.rs` — 3 pontos (barra
  readonly, agenda readonly, barra editável de Mês)
- `ui/src/components/embeds/inline_table.rs` — 4 tipos de célula
  (Date/PageLink/MultiSelect/Select)
