# Ciclo 143 - done

## Resumo

Dois bugs reais reportados pelo usuário: `"[ ]"`/`"[]"` não criava
checkbox, e não dava pra combinar lista + checkbox manualmente. Quatro
causas raiz: (1) não existia atalho de digitação pra checkbox; (2)
`html_to_md.rs`'s ramo `"li"` duplicava o marcador quando o conteúdo
já era um checkbox (`"- - [ ] texto"`); (3) o ramo `"input"` sempre
emitia desmarcado, nunca lia o `checked` real; (4) clicar num checkbox
pra marcar/desmarcar nunca era persistido (só dispara `"click"`, não
`"input"`). Corrigidos os quatro juntos, mais o template do slash
command "Checklist" ajustado pra gerar a mesma estrutura
(`<ul><li><input>`) que o round-trip real produz.

## Arquivos criados/modificados

- `ui/src/components/editor.rs` — atalho `"[]"`/`"[ ]"` + espaço em
  `apply_block_shortcut`; `on_wysiwyg_click` persiste toggle de
  checkbox; template do slash item "Checklist" vira `<ul><li>`
- `ui/src/html_to_md.rs` — ramo `"li"` não duplica marcador quando o
  conteúdo já é um checkbox; ramo `"input"` lê `checked` real
