# Ciclo 073 - done

## Resumo

Corrige dois bugs reportados no menu `/` do editor: lista não rolava pra
mostrar o item ativo ao navegar com teclado, e clicar num item com o
mouse aplicava o item errado (o destacado por teclado, não o clicado).

## Arquivos criados/modificados

- `ui/src/components/editor.rs` — `NodeRef` + efeito de
  `scroll_into_view` no item ativo; `select_slash` muda de `Callback<()>`
  pra `Callback<usize>` (recebe a posição do item clicado/navegado em vez
  de sempre ler `*slash_idx`); `prevent_default()` no `onmousedown` dos
  itens do menu
- `ui/Cargo.toml` — features `ScrollIntoViewOptions`/
  `ScrollLogicalPosition` do `web-sys`

## Testes

`cargo test --lib`: 52 passaram (sem testes novos — bug de UI pura, sem
lógica de dados nova).

`trunk build` + `cargo build --manifest-path src-tauri/Cargo.toml`: OK.

## Validação ao vivo (MCP tauri)

Navegar com seta até "Título 3" (destacado por teclado) e depois clicar
com o mouse em "Linha" (item diferente) — HTML resultante teve `<hr>`
inserido corretamente, confirmando que o item CLICADO foi aplicado, não
