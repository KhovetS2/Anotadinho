# 295 — O retângulo fechado, e o fundo que saiu

```
## Critérios de aceite
┌─────────────────────────────────────────────────────────┐
│  - [ ] cargo build --workspace exit 0                   │
│  - [ ] cargo test --workspace exit 0 (todos os testes…  │
│  - [ ] cargo clippy --workspace --all-targets           │
└─────────────────────────────────────────────────────────┘
```

## Dois destaques competindo

A linha em foco tinha fundo de destaque desde que a TUI existe. Com a
moldura do ciclo 294 fazendo o mesmo trabalho, os dois passaram a
competir — e havia um efeito colateral que eu não tinha notado: **texto
colorido por cima de fundo perde a cor do tipo dele**. Um título em
ciano dentro de um fundo ciano é só um retângulo.

Saiu o fundo. Ficou a moldura.

O realce de fundo continua na lista de páginas, e isso é de propósito:
ali não há moldura pra marcar, então ele ainda é o único sinal.

## As quatro bordas, e o texto que cabe

O retângulo tinha topo e fundo, e o texto escapava pelos lados. Sem as
laterais ele não lê como retângulo — lê como dois traços soltos.

Com as laterais veio a consequência: linha mais longa que a caixa
empurraria o `│` da direita pra fora, e a moldura quebraria justo na
linha mais longa. Corte com `…` resolve, e é a resposta certa: cortar é
honesto, transbordar mente sobre onde a caixa acaba.
