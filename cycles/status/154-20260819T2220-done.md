documentado no `guia-agent-os.md` só era navegável na mão: a única
visão agregada era um kanban MANUAL. Agora qualquer recorte do vault

## Testes adicionados

- consulta vazia devolve tudo; filtro por pasta; tags em AND
- cada operador (`eq`, `neq`, `contains`, `exists`, `gt`, `lt`)
- `neq` inclui página SEM o campo (o trabalho não classificado)
- `gt` numérico vs alfabético (10 > 5, mas data como texto)
- ordenação asc/desc com ausentes no fim; limite; campo vazio ignorado
- round-trip YAML (o campo de condições sai como `where`)

## Problemas encontrados

- **Bug pré-existente:** Escape dentro de qualquer modal fecha o modal
  E desseleciona a página aberta (`Modal` não faz `stop_propagation`,
  o Escape chega no listener global do `app.rs`). Virou a **task 161**
  pela regra de isolamento — não é regressão deste ciclo, vale desde o
  ciclo 124.
