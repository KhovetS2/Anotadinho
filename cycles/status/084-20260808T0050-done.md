# Ciclo 084 - done

## Resumo

Generaliza o mecanismo de inserção via `Range` do ciclo 079
(`insert_embed_marker_at_cursor`) pra TODOS os itens do menu `/`, não só
embeds — corrige um bug real (menor, mas real) onde título/lista/quote/
código/linha/tabela markdown inseridos dentro de um item de lista viravam
texto literal em vez do bloco de verdade (ex: `- # Título` em vez de um
heading).

## Arquivos criados/modificados

- `ui/src/components/editor.rs` — `insert_element_at_cursor` (genérico,
  extraído de `insert_embed_marker_at_cursor`), `parse_single_element`,
  todos os itens do menu `/` (título/lista/checklist/citação/código/
  linha/tabela/imagem/diagrama/assets) migrados de `execCommand` pra
  essa inserção, com `mark_edited` explícito depois de cada inserção
  (Range/insertBefore não disparam `oninput` sozinhos)
