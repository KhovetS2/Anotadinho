# Ciclo 224 concluído — Prompts padrão reutilizáveis

## O que foi feito

- Criado no core o contrato de prompts padrão, com descoberta restrita por
  pasta e tipo, parsing ordenado de variáveis, deduplicação, expansão,
  detecção de pendências, contexto e rascunho ao final para moldes sem
  marcador.
- Valores interpolados passam pela blindagem de DADO do ciclo 202, inclusive
  quando tentam reproduzir os próprios delimitadores.
- O compositor da conversa ganhou seletor com opção vazia, campos de
  variáveis, aviso de pendência, preview sem envio e persistência dos anexos
  declarados em `contexto:`.
- Adicionado cenário de harness para filtro, ordem, repetição, pendência,
  escrita livre, preview e contexto, além de testes puros do motor.

## Como foi verificado

- `cargo test --workspace` — 477 testes passaram na execução completa; o
  teste adicional de marcador único passou depois, elevando o total atual a
  478.
- `trunk build` — passou com uma toolchain temporária contendo o alvo
  `wasm32-unknown-unknown`, ausente no Rust do sistema.
- `cargo build --manifest-path src-tauri/Cargo.toml` — passou.
- `node scripts/uitest/run.mjs 224` — 1/1 cenário passou contra o app real.
- `node scripts/uitest/run.mjs` — 144/146 na passagem completa; os dois
  cenários antigos que oscilaram por timing passaram imediatamente quando
  repetidos isoladamente. O cenário 224 e o snapshot visual passaram.
- `git diff --check` — passou.
